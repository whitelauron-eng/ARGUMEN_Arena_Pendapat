# ARGUMEN — Arena Pendapat
Game web edukasi ringan untuk materi Bahasa Indonesia kelas III, Bab 2 “Yuk, Berpendapat!”

## Cara mencoba
Ekstrak ZIP lalu buka `index.html` di browser.

## Upload ke GitHub Pages
1. Buka repositori GitHub-mu.
2. Unggah `index.html`, `style.css`, dan `game.js` langsung ke direktori utama repositori.
3. Klik **Commit changes**.
4. Buka **Settings → Pages**.
5. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu simpan.
6. Tunggu proses selesai dan buka alamat Pages yang ditampilkan GitHub.

## Kontrol
Klik kartu di bagian bawah, lalu klik petak kosong. Tombol `?` membuka panduan; `Baca teks pemantik` membuka bacaan; `Mulai ulang` memulai pertandingan baru.

Prototipe ini menggunakan HTML, CSS, dan JavaScript tanpa framework atau aset eksternal, sehingga ringan. Materi kartu dan bacaan adalah materi pengembangan bertema berpendapat; cocokkan kembali dengan halaman buku yang digunakan sebelum dipakai sebagai asesmen formal.
